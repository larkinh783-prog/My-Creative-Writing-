# My Creative Writing
A small iPhone-friendly writing app prototype.

## Features in this starter version
- Poems: create, edit and delete
- Stories: title, summary, started/completed dates
- Story-specific character profiles
- Story chapters with summaries, editor and word counts
- Ideas list with used checkboxes and up/down reordering
- Export/import JSON backup
- Export a story as a plain text manuscript

## Important storage note
Data is saved in local browser storage on this device/browser. Export backups regularly. Clearing website data or changing browser/device can remove access to locally stored data.

## Publish with GitHub Pages
Upload `index.html` to the root of your GitHub repository, then enable Pages from the repository's Settings > Pages, using the main branch and root folder.
